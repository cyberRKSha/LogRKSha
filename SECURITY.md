# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in LogRKSha, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, send an email to the repository maintainer with the following details:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide updates as the issue is investigated and resolved.

## Scope

This policy applies to the LogRKSha codebase and its configuration. Third-party dependencies are maintained by their respective projects.

## Supported Versions

Only the latest release on the `master` branch receives security updates.
